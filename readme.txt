Give your team a focused workspace for editing selected pages, posts, events, products and newsletters.

== Description ==

Administrators choose which content each editor can change. The visual editor supports text, images, links and buttons. For published pages and posts, administrators can require approval and assign reviewers. The public page keeps its current content while a proposal awaits review.

Editors can choose images from the media library. Administrators control whether editors can share images or access the full library.

Optional integrations include Advanced Custom Fields, The Events Calendar and WooCommerce. Permissions for simple products cover descriptions, images, categories, regular prices and inventory. The newsletter module manages drafts, lists and campaigns and uses the site's WordPress mail transport.

== Installation ==

1. Upload the plugin ZIP under Plugins, Add New Plugin, then activate Dendrila Simple Edit.
2. Open Edit my site and select the content and modules your team may use.
3. Assign the simple editing role to the accounts that need it.
