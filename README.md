# Dendrila Simple Edit

Extension WordPress indépendante pour modifier uniquement les contenus explicitement autorisés, sans accès à la mise en page ni à l'administration technique.

> Le dépôt démarre ici. L'interface, les permissions et les intégrations sont développées par lots. Ne pas installer comme une extension terminée à ce stade.

- Nom : **Dendrila Simple Edit**.
- Slug prévu : `dendrila-simple-edit`.
- Rôle prévu : « Responsable du site » (`dendrila_site_manager`).
- Source des données : WordPress, sans serveur Dendrila requis.
- Dendrila CMS sert de référence conceptuelle ; aucune dépendance à son noyau PHP 8.5.
